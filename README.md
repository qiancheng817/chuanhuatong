# 传话筒 chuanhuatong

[Songloft](https://github.com/songloft-org/songloft) JS 插件：让**小爱音箱**与**企业微信**实现双向传话。**纯插件，无需部署任何中间件 / Docker**（配合官方 [MIoT 插件](https://github.com/songloft-org/songloft-plugin-miot)使用）。

- 孩子在家对小爱说：「**小爱同学，告诉爸爸，我想吃西瓜**」
- 爸爸的企业微信收到：「【孩子传话】我想吃西瓜」
- 爸爸或妈妈直接在机器人会话打字：「**好，下班买**」
- 小爱音箱直接播报：「**好，下班买**」（无前缀称呼）

支持三种传话开头：「**告诉爸爸，xxx**」「**告诉妈妈，xxx**」「**告诉爸爸和妈妈，xxx**」（另兼容「告诉爸爸妈妈」「告诉爸妈」），都推送到同一个企业微信目标。

## 工作原理

```
孩子语音
   │
   ▼
小爱音箱 ──MiNA 云端对话轮询──► MIoT 插件（songloft-plugin-miot）
                                   │ 对话监听 Webhook（POST）
                                   ▼
                      传话筒插件 /relay/inbound（本插件，免 JWT）
                                   │ 推送
                                   ▼
                    企业微信群机器人 Webhook ──► 爸爸（孩子→爸爸）

爸爸打字 ──► 企微智能机器人 ──WebSocket 长连接──► 传话筒插件
                                   │ 宿主 JWT 调 MIoT /mina/tts
                                   ▼
                                小爱音箱播报（爸爸→孩子）
```

两条方向分别复用现成能力，因此无需自建服务：

| 方向 | 复用能力 |
|---|---|
| 孩子 → 爸爸 | MIoT 插件的「对话监听 Webhook」+ 企微群机器人 Webhook（或智能机器人长连接） |
| 爸爸 → 孩子 | 企微「智能机器人」WebSocket 长连接（本插件内置客户端）+ MIoT 插件的 `/mina/tts` |

> 插件维持的 WebSocket 长连接会被宿主 `HealthChecker` 识别为活跃连接，**不会被空闲休眠**。

## 前置条件

1. 已安装官方 MIoT 插件，登录小米账号
2. MIoT → 设备：勾选要管理 / 监听的小爱音箱
3. MIoT → 语音 → 开启「**启用对话监听**」（截图里的开关），轮询间隔建议 1–3 秒

## 部署步骤

### 第一步：创建企业微信智能机器人（用于爸爸回话）

1. 企业微信客户端 → **工作台 → 智能机器人 → 创建机器人 → 手动创建**
2. 选择 **API 模式创建**
3. 连接方式选择 **「使用长连接」**（无需公网域名 / IP）
4. 保存生成的 **Bot ID** 和 **Secret**
5. 配置机器人**可见范围**（包含你自己），保存
6. 打开机器人单聊，先发一句话（如「你好」）激活会话

### 第二步：（推荐）创建企微群机器人（用于接收孩子传话）

在任意企微群 → 右上角 `…` → 消息推送（群机器人）→ 添加，复制 **Webhook 地址**：

```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx
```

> 群机器人推送最可靠（不依赖会话状态）。若你只在智能机器人单聊里收发，也可不建群机器人——此时孩子→爸爸会走智能机器人长连接推送（前提是你先在机器人里说过话）。

### 第三步：安装并配置传话筒插件

1. 下载本仓库 `dist/chuanhuatong.jsplugin.zip`
2. Songloft → 设置 → 插件管理 → 上传并启用「传话筒」，打开插件页面
3. 填写并保存：

| 配置项 | 说明 |
|---|---|
| 智能机器人 Bot ID / Secret | 第一步获取（爸爸→孩子必填） |
| 群机器人 Webhook | 第二步获取（孩子→爸爸，推荐填） |
| 唤醒词 | 孩子语音必须以其中一个开头，逗号分隔，默认 `告诉爸爸 / 告诉妈妈 / 告诉爸爸和妈妈`（另兼容 `告诉爸爸妈妈` `告诉爸妈`） |
| 发送方称呼 | 推送署名，默认 `孩子` |
| 小爱播报前缀 | 回话的播报前缀，**默认留空，直接播报内容** |
| 企微确认语 | 大人发消息后的回执，默认 `已转告小爱音箱` |

保存后页面顶部「企微长连接」应显示 **已连接**。

### 第四步：对接孩子语音（自动 / 手动，二选一）

孩子语音由 MIoT 插件轮询，需要把本插件登记为它的「对话 Webhook」。**默认自动模式，无需任何额外操作。**

**方式 A：自动注册（默认，推荐）**

- 在插件页「入站对接」卡片选择 **自动注册**，地址栏会显示 Webhook 地址；
- 插件会**自动调用 MIoT 接口**完成注册（初始化时带重试，也可随时点「**立即注册**」）；
- 状态显示「**已注册**」即成功。

**方式 B：手动填写**

- 在「入站对接」卡片选择 **手动填写**，点「**复制地址**」拿到 Webhook 地址；
- 打开 **智能音箱插件 → 语音 → Webhook 回调**，名称随意（如「传话筒」），粘贴地址，点「添加」。

> 该地址已在插件 `publicPaths` 中声明免鉴权；地址由插件根据 Songloft 实际地址自动生成，无需手敲。

### 第五步：验证

插件页面「连通性测试」：

1. **测试企微推送** — 企业微信应收到「传话筒连通性测试」
2. **测试小爱播报** — 小爱应播报「传话筒连通性测试」

然后实际让孩子说一次：「小爱同学，告诉爸爸，我放学啦」。「传话记录」里可看到每条消息的状态与失败原因。

## 常见问题

**Q：「企微长连接」一直未连接？**
A：确认 Bot ID / Secret 正确（是「API 模式 / 长连接」机器人，不是群机器人）；保存配置会自动重连。

**Q：测试企微推送失败 / 孩子说话没收到？**
A：① 优先填「群机器人 Webhook」；② 若走智能机器人长连接推送，需先在机器人单聊里发过一句话；③ 查看「传话记录」的失败详情。

**Q：测试小爱播报提示「目标音箱未知」？**
A：让孩子先说一次「告诉爸爸…」，插件会自动记住设备；或在「MIoT 插件（高级）」里手动填固定 account_id / device_id。

**Q：孩子说了但没反应？**
A：依次确认：① MIoT「启用对话监听」已开、设备已勾选；② 「入站对接」状态为「已注册」（自动模式可点「立即注册」，或手动添加）；③ 语音以唤醒词开头。

**Q：有几秒延迟？**
A：MiNA 云端对话按轮询间隔同步（默认 1–3 秒），属云端方案的正常延迟。

## 本地构建

Windows 下执行（无需 Node.js / Python）：

```powershell
.\scripts\build.ps1
```

产物输出到 `dist/chuanhuatong.jsplugin.zip`，自动计算并写入 `entryHash` / `zipHash`。
